# P1106 删数问题 —— 单调栈经典入门

## 一、题目核心

给定一个高精度正整数 `n`（最多250位），删除其中 `k` 个数字。

删除后：

- 剩余数字保持原来的左右顺序；
- 不能重新排列；
- 要使最终得到的数字最小。

例如：

```
175438
k = 4
```

删除后：

```
13
```

答案为 `13`。

---

# 二、关键思考：为什么不能排序？

最开始容易想到：

> 排序后留下最小的 k 个数字。

但是错误。

原因：

题目要求：

> 删除数字后保持原顺序。

例如：

```
987654
```

如果排序：

```
456789
```

留下：

```
4567
```

但原字符串中：

```
4 5 6 7
```

的顺序是反的，无法通过删除得到。

所以：

**删除问题 ≠ 排序选择问题**

---

# 三、贪心思想

目标：

让高位尽可能小。

因为数字比较大小时：

```
最高位 > 后面的所有位
```

例如：

```
923
```

和：

```
823
```

只比较第一位：

```
8 < 9
```

所以应该优先保证前面的数字小。

---

观察：

如果出现：

```
前面的数字 > 后面的数字
```

例如：

```
175438
```

中的：

```
7 > 5
```

那么：

```
7
```

一定应该删除。

因为删除后：

```
15438
```

比：

```
17538
```

更小。

所以：

遇到后面的数字更小时，删除前面的“大数字”。

---

# 四、为什么使用单调栈？

我们需要维护一个：

**从左到右递增的数字序列**

例如：

输入：

```
175438
```

过程：

加入：

```
1
```

加入：

```
7

1 7
```

遇到：

```
5
```

发现：

```
7 > 5
```

删除7：

```
1 5
```

继续：

遇到4：

```
5 > 4
```

删除5：

```
1 4
```

继续：

遇到3：

```
4 > 3
```

删除4：

```
1 3
```

最终：

```
13
```

这就是单调栈。

# 五、数组模拟栈

竞赛中推荐使用数组模拟。

定义：

```java
char[] stk;
int top;
```

其中：

- `stk` 保存栈元素；
- `top` 表示当前有效元素数量。

---

## 入栈

```java
stk[top++] = c;
```

例如：

```
1 5
```

加入：

```
8
```

变成：

```
1 5 8
```

---

## 弹栈

```java
top--;
```

不需要真的删除数组元素。

因为：

有效范围是：

```
[0, top)
```

例如：

数组：

```
1 5 8
```

top：

```
3
```

执行：

```
top--
```

之后：

```
top=2
```

有效元素：

```
1 5
```

---

# 六、算法模板

```java
for(char c : n.toCharArray()){

    while(top>0 
          && k>0 
          && stk[top-1]>c){

        top--;
        k--;
    }

    stk[top++]=c;
}
```

含义：

如果：

- 栈不为空；
- 还有删除次数；
- 栈顶数字比当前数字大；

删除栈顶。

---

# 七、剩余删除

如果遍历结束：

还有 k 没删除。

说明剩下的是递增序列：

例如：

```
12345
```

删除：

```
2个
```

应该删末尾：

```
345
```

所以：

```java
while(k>0){
    top--;
    k--;
}
```

# 八、易错点总结

## 1. 不能排序

错误：

```java
Arrays.sort()
```

因为会改变数字顺序。

---

## 2. 全部删除前导0

例如：

输入：

```
1000
k=3
```

结果：

```
0
```

不能输出空字符串。

需要判断：

```java
if(start==top)
    输出0;
```

---

## 3. 比较符号

求最小：

```java
stk[top-1] > c
```

维护递增栈。

求最大：

```java
stk[top-1] < c
```

维护递减栈。

---

# 九、复杂度分析

设数字长度为 n。

每个数字：

- 最多入栈一次；
- 最多出栈一次。

所以：

时间复杂度：

```
O(n)
```

空间复杂度：

```
O(n)
```

本题：

```
n <= 250
```

完全满足要求。
